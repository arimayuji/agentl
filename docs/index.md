# agentl

Agentic ETL for Python. Declare pipelines in YAML where each step is a connector, a function or an
LLM agent, with validated outputs, per-record cache, cost budgets, a live dashboard and notifications.
Install with `pip install agentl-etl`, then read [Getting started](getting-started.md).

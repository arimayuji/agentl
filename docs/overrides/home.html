ETL pipelines where any step
can be an LLM agent.

Declare the pipeline in one YAML file. Connectors read and write your data, Python functions transform it, and agent steps handle the parts that need judgement, with validated output, per-record cache, cost budgets and a live dashboard.

One file

The whole pipeline, readable in a code review.

# pipeline.yaml
name: invoices
llm: { provider: anthropic, model: claude-opus-5-5 }

steps:
  - id: invoices
    use: csv.read
    with: { path: data/invoices.csv }

  - id: classify
    agent: Classify the expense and flag odd ones.
    input: invoices
    output: { category: str, review: bool? }

  - id: save
    use: postgres.write
    input: classify
    with: { dsn: ${DATABASE_URL}, table: invoices }
